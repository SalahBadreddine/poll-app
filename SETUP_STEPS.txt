===========================================
IMMEDIATE STEPS TO FIX THE WHITE SCREEN
===========================================

1. STOP ALL RUNNING PROCESSES
   - Close any terminal windows running npm run dev
   - Close any terminal windows running npm run dev:server
   - Close the browser tab

2. FILL IN YOUR .env FILE
   Open the .env file that was just created and:
   
   A) Get your Neon database URL:
      - Go to https://console.neon.tech/
      - Click on your project
      - Copy the connection string
      - It looks like: postgresql://user:pass@host/database
   
   B) Generate a JWT secret (run this in terminal):
      node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"
      Copy the output
   
   C) Update .env file:
      DATABASE_URL=paste_your_neon_url_here
      JWT_SECRET=paste_your_generated_secret_here
      PORT=3001

3. INITIALIZE DATABASE
   - Go to Neon SQL Editor
   - Copy everything from database/schema.sql
   - Paste and run it in the SQL Editor
   - This creates all the tables

4. START THE APPLICATION
   
   TERMINAL 1 (Backend):
   npm run dev:server
   
   TERMINAL 2 (Frontend):
   npm run dev

5. CHECK
   - Visit http://localhost:5173
   - Should see the homepage
   - Click Login to create an account
   - Should work without white screen

If you still see white screen:
- Check browser console (F12) for errors
- Check terminal for error messages
- Make sure .env has correct values (no quotes around the values!)
