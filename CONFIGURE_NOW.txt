═══════════════════════════════════════════════════════════════════
STEP 1: Get Your Neon Database Connection String
═══════════════════════════════════════════════════════════════════

1. Go to: https://console.neon.tech/
2. Sign in
3. Open your project (or create one if you don't have one)
4. Click "Connection Details" or find the connection string
5. It will look like:
   postgresql://username:password@ep-xxx-xxx.region.aws.neon.tech/neondb?sslmode=require

6. COPY THAT STRING! You'll need it in step 3.

═══════════════════════════════════════════════════════════════════
STEP 2: Initialize Your Database
═══════════════════════════════════════════════════════════════════

1. In Neon Console, click "SQL Editor" or "Query"
2. Open the file: database/schema.sql
3. COPY THE ENTIRE CONTENTS
4. Paste it into the SQL Editor in Neon
5. Click "Run" or press F5
6. You should see success messages
7. This creates the tables: users, polls, questions, options, votes

═══════════════════════════════════════════════════════════════════
STEP 3: Generate JWT Secret
═══════════════════════════════════════════════════════════════════

Run this command in your terminal:

node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"

COPY the output (it will be a long random string)

═══════════════════════════════════════════════════════════════════
STEP 4: Update .env File
═══════════════════════════════════════════════════════════════════

Open the .env file in your project root and replace with:

DATABASE_URL=YOUR_NEON_CONNECTION_STRING_FROM_STEP_1
JWT_SECRET=YOUR_RANDOM_STRING_FROM_STEP_3
PORT=3001

IMPORTANT: No quotes around the values!

═══════════════════════════════════════════════════════════════════
STEP 5: Restart Backend Server
═══════════════════════════════════════════════════════════════════

1. Stop the current backend server (Ctrl+C)
2. Run again: npm run dev:server
3. Make sure you see: "Server running on http://localhost:3001"
4. Try registering again!
